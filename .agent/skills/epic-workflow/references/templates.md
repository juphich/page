# 작업 문서 템플릿

## Backlog 문서

파일명: `백로그_<제목>.md`

전체 문서는 빈 줄을 포함해 50줄 이하여야 한다.

```markdown
# 백로그 <제목>

## 배경

<이 backlog가 필요한 이유>

## 목표

<달성하려는 하나의 목표>

## 범위

- <포함할 범위>

## 기대 결과

- <완료되었을 때 기대하는 결과>

## 참고

- <관련 자료 또는 없음>
```

## Epic 문서

## `index.md`

```markdown
# <에픽코드> <에픽제목>

## 목적

<이 epic이 달성할 결과>

## 배경

<필요한 배경과 문제 정의>

## 범위

- <포함 범위>

## 제외 범위

- <포함하지 않는 범위>

## 완료 조건

- [ ] <epic 완료 조건>
```

## `plan.md`

```markdown
# <에픽코드> 작업 계획

## Task

- [ ] [<티켓코드> <태스크 제목>](<티켓코드>_<태스크 제목>.md)
  - [ ] <세부 체크리스트>
  - [ ] <검증 체크리스트>
```

## Task 문서

task 코드: `pt-xxxx` (`xxxx`는 0으로 채운 네 자리 숫자)

파일명: `pt-xxxx_<태스크 제목>.md`

```markdown
# <티켓코드> <태스크 제목>

## 목표

<이 task가 완료할 구체적인 결과>

## 작업 내용

- <구현 또는 조사 범위>

## 완료 조건

- [ ] <완료 조건>

## 결정 사항

- <작업 중 확정한 중요한 결정>

## 검증

- <실행한 검사와 결과>

## 후속 작업

- <필요한 후속 task 또는 없음>
```
