# 요구사항

## 1. 배경

간트차트를 만들고 편집하려면 보통 전용 SaaS나 데스크톱 앱이 필요하다. 이 프로젝트는 **설치·계정·서버 없이** 브라우저만으로 간트차트를 만들고, 그 결과물을 다른 사람에게 파일 하나로 전달하며, 받은 사람도 같은 방식으로 다시 편집할 수 있게 한다.

산출물은 언제나 **단일 HTML 파일**이다. 이 파일은 "결과물(보고서)"인 동시에 "편집기"다.

## 2. 원본 요구사항

1. 스탠드얼론으로 독립 작동한다.
2. 간트차트를 HTML 파일로 내보낼 수 있다.
3. 보고서 형식으로 생성된 HTML 간트차트 파일은 JavaScript를 자체 내장하여 편집모드로 전환·편집할 수 있다.
4. 편집모드 편집은 별도 전용 툴 없이 브라우저 로컬에서 가능하다.
5. 온전한 HTML 간트차트는 PDF로 출력할 수 있다.

## 3. 기능 요구사항

### 3.1 스탠드얼론 (요구 1)
- 외부 네트워크 요청 없이 동작한다. CDN·폰트·이미지 등 원격 리소스에 의존하지 않는다.
- `file://` 로 연 상태에서 모든 기능이 동작해야 한다.
- 모든 코드(HTML/CSS/JS)와 데이터가 단일 파일에 인라인된다.

### 3.2 내보내기 (요구 2)
- 현재 편집 상태를 완전한 HTML 문자열로 재조립해 파일로 저장한다.
- 저장된 파일은 원본과 동일하게 열리고 편집 가능해야 한다(왕복 안정성).

### 3.3 자체 내장 편집 (요구 3·4)
- 내보낸 파일 자체가 뷰어·에디터 JS를 품는다. 별도 도구·확장·서버 불필요.
- 보기 모드 ↔ 편집 모드 전환.
- 편집 기능:
  - 태스크 추가/삭제
  - 이름·시작일·종료일·진행률·색상 편집
  - 막대 드래그로 이동, 양끝 리사이즈로 기간 조절
  - 차트 제목 편집
- 편집 결과는 다시 저장(3.2)으로 파일에 영속화된다.

### 3.4 PDF 출력 (요구 5)
- 브라우저 인쇄 기능으로 PDF 저장이 가능해야 한다.
- 인쇄 시 편집 UI(툴바·편집표·리사이즈 핸들)는 숨긴다.
- 색상·음영이 그대로 인쇄된다(print-color-adjust).

## 4. 비기능 요구사항

- **의존성 0**: 빌드 도구·프레임워크·런타임 없이 순수 웹 표준만 사용.
- **브라우저 호환**: Chrome/Edge(권장, 파일 덮어쓰기 저장), Firefox/Safari(다운로드 저장으로 폴백).
- **데이터 이식성**: 데이터는 파일 내 `<script type="application/json">`에 사람이 읽을 수 있는 형태로 보관.
- **안전한 왕복**: 저장 시 렌더링된 전이(transient) DOM 상태가 파일에 섞이지 않는다.

## 5. 범위 밖 (현 단계)

- 다중 사용자 실시간 협업, 서버 동기화
- 계정·권한·클라우드 저장
- 간트 외 보고서 유형(추후 확장 대상)
- 자동 일정 계산(임계경로 등)
