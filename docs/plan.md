# PAGE 프로젝트 Epic 계획

| 순서 | Epic | 단계 | 목표 | 주요 범위 | 선행 Epic | 상태 |
|---:|---|---|---|---|---|---|
| 1 | `ep-0001_page_generator` | MVP | Markdown의 `page:gantt`를 단일 PAGE HTML로 변환하는 CLI를 완성한다. | 문법·CLI 계약, 중간 모델, Markdown 파서, Gantt 검증, HTML 템플릿, 파일 입출력, 통합 테스트 | 없음 | 진행 예정 |
| 2 | `PAGE-E002_간트 자기 편집과 저장 안정화` | MVP | 생성된 HTML에서 간트를 편집하고 저장한 뒤 다시 열어 편집할 수 있게 한다. | 편집 모드, 태스크·제목 편집, 막대 이동·리사이즈, HTML 재저장, 왕복 안정성 | ep-0001 | 계획 |
| 3 | `PAGE-E003_스탠드얼론과 PDF 검증` | MVP | 오프라인 실행, 브라우저 호환과 PDF 출력 수용 기준을 충족한다. | 외부 의존성 제거, 브라우저별 저장 폴백, 인쇄 스타일, E2E 검증 | ep-0001, E002 | 계획 |
| 4 | `PAGE-E004_일반 Markdown과 page-report` | 확장 | 일반 Markdown 콘텐츠와 구조화된 보고서 생성을 지원한다. | 제목·본문·표 렌더링, `page:report` 모델과 런타임 | E003 | 계획 |
| 5 | `PAGE-E005_page-chart 시각화` | 확장 | 데이터셋과 옵션을 기반으로 차트를 생성하고 편집할 수 있게 한다. | 차트 모델, 렌더러, 편집 UI, 저장 | E004 | 계획 |
| 6 | `PAGE-E006_Mermaid 호환` | 확장 | Mermaid 호환 변환과 변환 불가 유형의 정적 렌더링을 지원한다. | Mermaid 블록 식별, PAGE 모델 변환, 정적 렌더링 폴백 | E004 | 계획 |
| 7 | `PAGE-E007_간트 PDF 고도화` | 고도화 | 긴 일정의 PDF 축소 또는 페이지 분할을 지원한다. | 인쇄 스케일, 주·월 단위 분할, 페이지 잘림 방지 | E003 | 계획 |
| 8 | `PAGE-E008_간트 일정 모델 확장` | 고도화 | 의존관계, 마일스톤, 태스크 그룹과 요약 일정을 지원한다. | 선후행 관계, 마일스톤, 그룹 접기, 요약 막대 | E003 | 계획 |
| 9 | `PAGE-E009_편집 생산성 고도화` | 고도화 | 반복 편집과 대량 입력의 생산성을 높인다. | Undo/Redo, CSV·JSON 가져오기 | E002 | 계획 |

MVP 범위는 ep-0001부터 E003까지다. ep-0001이 완료되면 `page input.md -o output.html` 흐름으로 최초 PAGE 문서를 생성할 수 있어야 한다. 확장 및 고도화 Epic은 MVP 완료 후 우선순위를 다시 검토한다.
