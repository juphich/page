# pt-0009 PDF 출력 구현

## 목표

생성된 PAGE HTML을 로컬 브라우저 인쇄 엔진으로 PDF 파일에 출력한다.

## 작업 내용

- 지원하는 Chromium 계열 브라우저 탐지 정책을 구현한다.
- 임시 HTML을 headless 인쇄로 PDF 변환한다.
- 브라우저 부재, 실행 실패와 불완전한 PDF를 진단한다.
- 성공과 실패 모두에서 임시 파일을 정리한다.

## 완료 조건

- [ ] `page input.md --format pdf -o output.pdf`가 동작한다.
- [ ] PDF에 차트와 계산된 그룹 진행률이 표시된다.
- [ ] HTML에 적용된 기본 스타일과 사용자 CSS가 PDF에도 동일하게 적용된다.
- [ ] 변환 실패 시 기존 출력 파일을 보존한다.

## 결정 사항

- HTML과 PDF는 같은 런타임 렌더링 결과를 사용한다.
- PDF 생성에는 로컬 Chromium 계열 브라우저가 필요하다.
- PDF 바이트 동일성은 보장하지 않는다.

## 검증

- PDF 파일 시그니처와 비어 있지 않은 페이지를 검사한다.
- 브라우저가 없는 환경의 오류 진단을 검사한다.
