# pt-0006 간트 런타임 템플릿 이관

## 목표

기존 간트 HTML 프로토타입을 Rust 생성기에 포함할 정식 런타임 템플릿으로 이관한다.

## 작업 내용

- 백업 프로토타입의 HTML, CSS와 JavaScript를 검토한다.
- 생성 데이터와 문서 제목 삽입 지점을 분리한다.
- 런타임 HTML, Gantt component CSS, 기본 테마, 인쇄 CSS와 JavaScript를 개발 소스에서 분리한다.
- Gantt를 공통 PAGE 문서 셸의 content 영역에 배치한다.
- 한 문서의 여러 Gantt component를 각자의 data block으로 독립 초기화한다.
- Gantt renderer가 사용할 의미 있는 class와 `data-*` 속성 계약을 정의한다.
- 평면 task 또는 milestone·epic·task 계층을 표시한다.
- 존재하는 Epic과 milestone에 완료 task 기반 진행률을 표시한다.
- 템플릿을 `page-core` 바이너리에 포함할 수 있게 구성한다.
- HTML, CSS와 JavaScript 텍스트 자산을 컴파일 시점에 단순하게 내장할 수 있도록 구성한다.

## 완료 조건

- [ ] 기존 간트 기능을 보존한 정식 템플릿이 준비된다.
- [ ] 템플릿 삽입 지점이 명확하고 중복되지 않는다.
- [ ] 화면, 테마와 인쇄 스타일이 역할별 CSS 파일로 분리된다.
- [ ] 기본 옵션만으로 문서와 Gantt의 완성된 기본 스타일이 적용된다.
- [ ] Gantt가 전체 문서 기본 스타일을 침범하지 않는 독립 component로 동작한다.
- [ ] 한 문서의 여러 Gantt가 서로 상태를 공유하지 않고 동작한다.
- [ ] 별도 runtime 디렉터리 없이 모든 기본 자산이 실행 파일에서 제공된다.

## 결정 사항

- Epic 행은 하위 task 일정 범위와 계산 진행률을 요약한다.
- Milestone 영역은 모든 하위 task 기준 계산 진행률을 표시한다.
- 그룹이 없는 평면 차트에는 그룹 진행률을 표시하지 않는다.
- 색상, 간격과 글꼴은 CSS custom property와 component CSS로 관리한다.
- 기본값은 `docs/style.md`의 PAGE 기본 스타일 계약을 따른다.
- 런타임 모델과 JavaScript는 구체적인 CSS 값을 소유하지 않는다.
- 기본 텍스트 자산은 우선 `include_str!`로 내장하며 별도 resource framework는 사용하지 않는다.
- 편집모드와 태스크 추가 버튼은 Gantt component마다 두고 해당 Gantt만 편집한다.
- HTML 저장과 PDF 출력 버튼은 문서 상단에 하나만 둔다.
- HTML 저장 시 모든 Gantt 인스턴스가 현재 상태를 자기 data block에 기록한 뒤 문서 전체를 재조립한다.
- ep-0001에서는 Gantt만 편집하며 Markdown 섹션 편집은 후속 epic에서 다룬다.
- 프로토타입 편집 표의 진행률과 색상 입력은 task 상태 선택으로 대체한다.
