# pt-0010 생성기 통합 테스트 작성

## 목표

Markdown 입력부터 단일 HTML 출력까지 생성기 전체 흐름을 검증한다.

## 작업 내용

- 정상·경계·오류 입력 fixture를 작성한다.
- CLI 실행, HTML 구조와 내장 JSON을 검증한다.
- 일반 Markdown 요소의 구조, 순서와 안전한 HTML 렌더링을 검증한다.
- dry-run 성공·실패와 출력 파일 부재를 검증한다.
- HTML과 PDF 출력 경로를 검증한다.
- 평면·계층 렌더링과 Epic·milestone 진행률 계산을 검증한다.
- 오프라인 산출물과 결정적 출력을 검사한다.
- 단일·복수 사용자 CSS의 부분 override, 지정 순서와 기본 스타일 보존을 검사한다.
- release 실행 파일만 복사한 환경에서 기본 HTML 생성이 동작하는지 검사한다.
- release 바이너리 크기와 주요 의존성을 측정해 검증 기록에 남긴다.

## 완료 조건

- [ ] 핵심 정상 및 실패 시나리오가 자동화된다.
- [ ] 전체 workspace 테스트가 통과한다.
- [ ] ep-0001 완료 조건을 검증할 수 있다.
- [ ] 외부 runtime 없는 단일 CLI 배포 조건과 측정된 바이너리 크기가 기록된다.

## 결정 사항

- `completed` task만 완료 수에 포함되는 시나리오를 검증한다.
- PDF 테스트는 지원 브라우저가 있는 환경에서 실행하고 없으면 원인이 명확한 진단을 검증한다.
