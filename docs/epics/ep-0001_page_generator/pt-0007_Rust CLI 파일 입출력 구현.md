# pt-0007 Rust CLI 파일 입출력 구현

## 목표

Markdown 파일을 검증하고 PAGE HTML/PDF로 변환하는 `page` 명령을 제공한다.

## 작업 내용

- 입력 경로, 출력 경로와 기본 출력명을 처리한다.
- `--format html|pdf`와 형식별 확장자를 처리한다.
- `--dry-run`으로 구문과 모델 정합성까지만 검사한다.
- 기존 파일 덮어쓰기 정책과 `--force`를 구현한다.
- 사용자 진단 메시지와 종료 코드를 정리한다.

## 완료 조건

- [ ] `page input.md -o output.html` 명령이 동작한다.
- [ ] `page input.md --dry-run`이 파일 생성 없이 동작한다.
- [ ] PDF 형식을 선택하면 PDF 출력 단계로 전달한다.
- [ ] 파일 및 입력 오류가 명확한 메시지와 실패 코드로 반환된다.

## 결정 사항

- dry-run에서는 출력 경로 검사, 브라우저 탐지와 파일 쓰기를 수행하지 않는다.
