# pt-0005 Gantt 파싱과 검증 구현

## 목표

`page:gantt` 본문을 Gantt 모델로 변환하고 잘못된 데이터를 명확히 거부한다.

## 작업 내용

- 합의된 문법을 typed model로 역직렬화한다.
- 평면 task와 선택적인 milestone·epic 계층을 파싱한다.
- 날짜, 시작·종료 순서, ID와 상태를 검증한다.
- 기본값과 안정적인 자동 ID 생성을 구현한다.

## 완료 조건

- [ ] 유효한 Gantt 블록이 중간 모델로 변환된다.
- [ ] 필드 오류가 위치와 원인을 포함한 진단으로 반환된다.

## 결정 사항

- MVP 입력에서 `progress` 필드는 지원하지 않는다.
- 상태를 생략하면 `미진행`으로 정규화하고 정의되지 않은 상태 값은 오류로 처리한다.
- 비어 있는 최상위·그룹 항목과 허용되지 않은 중첩은 오류로 처리한다.
- Epic과 milestone 진행률은 입력에서 허용하지 않고 task 상태로 계산한다.
