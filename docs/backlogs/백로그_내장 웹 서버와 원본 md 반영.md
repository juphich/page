# 백로그 내장 웹 서버와 원본 md 반영

## 배경

PAGE의 기본 사용 방식은 서버 없이 생성된 HTML 하나를 열어 편집하고 HTML로 다시 저장하는 것이다. 원본 Markdown은 최초 HTML 생성의 입력이므로 HTML에서 편집한 내용은 원본 md에 반영되지 않는다. 같은 md로 다시 생성하면 HTML에서 편집한 내용이 사라진다.

## 목표

CLI에 내장 웹 서버를 추가해 서버로 연 문서에서 편집을 확정하면 원본 md에 자동으로 반영하는 편의 기능을 제공한다.

## 범위

- `page serve` 등 로컬 웹 서버 실행 명령
- 편집 확정 이벤트를 받아 원본 md 파일을 갱신하는 서버 API
- 원본 md에서 각 PAGE 블록의 원문 위치를 기록하는 방식
- PAGE 블록 원문만 바꾸고 나머지 md 텍스트는 그대로 유지하는 갱신 규칙
- Gantt 데이터를 입력 문법에 맞는 YAML로 다시 쓰는 규칙
- 자동 할당된 ID를 md에 기록할지 생략할지에 대한 정책
- 서버 없이 HTML에서 md 파일로 내보내는 기능과의 관계

## 기대 결과

- 서버 없이 HTML 하나로 편집하는 기본 방식은 그대로 유지된다.
- 서버로 연 문서에서는 편집 확정 시 원본 md가 갱신되고 재생성해도 편집 내용이 보존된다.
- 갱신된 md에서 편집하지 않은 부분은 원본과 동일하다.
